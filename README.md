# توب تن بيكس — خمن بالمقلوب

**العب الآن:** <https://haider505.github.io/top10-peaks/>

لعبة مسابقات عربية لفريقين بنظام النقاط المعكوس: المرتبة `#1` هي الأعلى إحصائياً وتمنح **أقل** النقاط،
والمرتبة `#10` هي الأقل ضمن القائمة وتمنح **أعلى** النقاط.

- **157 سؤالاً** في **14 تصنيفاً**، كل سؤال بعشر إجابات مرتبة.
- ملف واحد مستقل: `index.html` — لا يحتاج خادماً ولا تثبيتاً.
- محرك مطابقة عربي من خمس طبقات: تطبيع، تجريد جذر، مطابقة جزئية، تحمّل أخطاء، حسم الالتباس.
- نمطان: تلقائي بالكتابة، ونمط المقدم بنافذة مستقلة.

## النشر على GitHub Pages (رابط عام يفتحه أي شخص)

المستودع جاهز للرفع. نفّذ هذه الخطوات مرة واحدة:

1. أنشئ مستودعاً جديداً **عاماً (Public)** على <https://github.com/new>، مثلاً باسم `top10-peaks`.
   لا تضف فيه README ولا .gitignore.

2. من مجلد المشروع، اربطه وادفع:

```bash
git remote add origin https://github.com/haider505/top10-peaks.git
git branch -M main
git push -u origin main
```

3. في صفحة المستودع: **Settings** ← **Pages** ← تحت `Build and deployment`
   اختر Source = `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`، ثم **Save**.

4. بعد دقيقة أو دقيقتين يصبح الرابط جاهزاً:

```
https://haider505.github.io/top10-peaks/
```

هذا رابط عام: أرسله لأي شخص ويفتح اللعبة مباشرة في المتصفح، على الجوال أو الآيباد أو اللابتوب.

### تحديث اللعبة لاحقاً

```bash
git add -A && git commit -m "تحديث الأسئلة" && git push
```

يتحدّث الموقع خلال دقيقة.

## نمط المقدم على جهازين

افتح الرابط في جهاز العرض (التلفزيون أو اللابتوب)، ثم افتح على جهاز المقدم:

```
https://haider505.github.io/top10-peaks/#host
```

شاشة المقدم تعرض مفتاح الإجابات كاملاً وأزرار المنح والخطأ، وشاشة العرض تتفاعل فوراً.
التزامن يعمل بين نافذتين على **الجهاز نفسه وبالمتصفح نفسه** (عبر `BroadcastChannel`)؛
على جهازين مختلفين استخدم لوحة المقدم المدمجة داخل الصفحة بدلاً من ذلك.

## إضافة أسئلة

طريقتان:

**من داخل اللعبة** — زر «إدارة الأسئلة»: إضافة وتعديل وحذف واستيراد/تصدير JSON،
ويُحفظ كل ذلك في متصفح الجهاز نفسه (`localStorage`) ولا ينتقل إلى الأجهزة الأخرى.

**من المصدر** — الأسئلة في `packs/*.json`، وكل ملف تصنيف أو أكثر:

```bash
python build.py --check   # تحقق فقط
python build.py           # تحقق ثم حقن الأسئلة في index.html
```

يرفض `build.py` البناء عند: تكرار معرّف أو نص سؤال، أو عدد إجابات غير 10،
أو مراتب غير 1..10، أو تكرار إجابة داخل السؤال، أو نقص حقل مطلوب،
أو بقايا صياغة في الأسماء.

### بنية السؤال

```json
{
  "id": "q_example",
  "category": "تصنيف",
  "prompt": "أكثر 10 ...",
  "direction": "#1 هو الأعلى (أقل النقاط) — #10 هو الأقل ضمن العشرة (أعلى النقاط)",
  "answers": [
    { "rank": 1, "label_ar": "الاسم", "label_en": "Name",
      "synonyms": ["بديل", "تسمية أخرى"],
      "metric": "الرقم أو الحقيقة التي تبرر الترتيب",
      "hint": "تلميح يُكشف بالتلميح 💡" }
  ]
}
```
